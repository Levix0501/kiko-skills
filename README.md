# kiko-skills

A lightweight collection of agent skills that speed up everyday development.

## Quick start

Install:

```sh
npx skills add Levix0501/kiko-skills
```

Then, inside your project:

```
/setup-kiko                       # once per project — initialize .kiko state
/kick-off <idea>                  # turn a rough idea into a shared goal
/create-spec                      # freeze it into an approved, build-ready spec
/implement .kiko/specs/<file>.md  # build it: implement → review → fix → complete
```

Each step hands off to the next; jump in wherever your work already is.
